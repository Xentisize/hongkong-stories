Credits & privacy · 製作名單與私隱說明

Credits · 製作

  • Engine: Godot Engine 4.7 — MIT Licence
  • Fonts: Fusion Pixel 12px monospaced (zh_hk / zh_hans) — SIL Open Font Licence 1.1; licence files ship inside the game package
  • Generated art: sprites, tiles and props generated with Seedream via OpenRouter, palette-processed onto the project palette; generation provenance (model, seed, palette, cost) ships alongside every asset
  • Backend: FastAPI + uvicorn; dialogue generated with DeepSeek via OpenRouter
  • Stories, characters and text: © the Hong Kong Stories team — the people are fiction, the streets are real

Privacy · 私隱說明

  • No accounts, no sign-up. 無帳號、無登記。
  • Saves stay in your browser (IndexedDB). Clearing site data clears progress — use the save code in-game as backup. 進度只存在你的瀏覽器內。
  • No personal data leaves your browser. The backend sees an anonymous session token and your sanitised in-game state only — never your files, never your identity. 後端只會收到匿名工作階段代號與遊戲內狀態。
  • Dialogue text you type is sent to the LLM provider to generate the reply. 你輸入的對話文字會傳送至語言模型服務以產生回覆。
  • Telemetry is counts only: error codes, token and spend totals — no message text, no addresses, no identifiers. 遙測只有錯誤代碼與用量計數。

Questions: open an issue on the project repository. 有問題請到項目倉庫開 issue。
